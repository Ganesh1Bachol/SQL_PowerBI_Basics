# 🚲 Toman Bike Share Dashboard: SQL to Power BI 📊

## 📌 Project Description

This project demonstrates a **basic data analysis workflow** using **SQL and Power BI** to help the fictional bike rental company **Toman Bike Share** make data-driven decisions. The focus is on revenue, profitability, and seasonal trends.

> **Client**: Toman Bike Share
